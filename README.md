# 🐘 PHP Learning Project

## 📌 Giới thiệu
Dự án này tổng hợp các kiến thức cơ bản và nâng cao trong quá trình học **PHP**, kèm theo ví dụ minh họa và demo thực tế.  
Mục tiêu giúp người học nắm vững nền tảng PHP và áp dụng vào xây dựng ứng dụng web.

## 📖 Nội dung chính
- 🔹 **Kiến thức PHP căn bản**: cú pháp, biến, toán tử, vòng lặp, hàm  
- 🔹 **Làm việc với Form**: xử lý dữ liệu người dùng nhập  
- 🔹 **Phương thức GET/POST**: truyền và nhận dữ liệu qua URL và form  
- 🔹 **Quản lý người dùng**: đăng ký, đăng nhập, phân quyền cơ bản  
- 🔹 **Kết nối CSDL MySQL bằng PHP**: CRUD (Create, Read, Update, Delete)  
- 🔹 **Cookie & Session**: quản lý trạng thái người dùng  
- 🔹 **Ví dụ demo**: các ứng dụng nhỏ minh họa kiến thức đã học  

## 🛠️ Công nghệ sử dụng
- **Ngôn ngữ**: PHP 8+  
- **CSDL**: MySQL  
- **Web Server**: Apache / Nginx  
- **Công cụ hỗ trợ**: XAMPP
